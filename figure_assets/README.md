# Manuscript Fig. 1 reproduction

Run `exp_CombinedResults` for the unified accelerated data, then use
`plot_CombinedResults` for data-only redraws from `results/combined_accelerated`.
PNG and visible FIG are saved in that folder; no PDF is exported.

`Fig1_layout.fig` freezes the final user-approved layout before the accelerated
rerun. The plotting entry now changes only curve YData. The original sample
points, legends, styles, fonts, axes limits and positions are retained and checked.
The user approved one exception: panel c's upper Y limit is extended from
-5.5 to -5 dB to show the accelerated result; tick spacing remains unchanged.

`Fig1_original.fig` is a byte-for-byte copy of WorkingCodes/Combined_Plots.fig.
It preserves the three-panel layout, axes, original curves and custom legend
assembled by WorkingCodes/exp_CombinePlots.m and exp_temp.m. Thus this folder
does not depend on WorkingCodes being available after release.

In the previous, historical combined figure, only Pilot-only (DFT) and Fixed-profile were added to panels (a)/(b), using
`results/scan_SNR_dB.mat` and `results/scan_Kp.mat` (100/50 trials per point).
These data were generated by exp_SNRVsMonteCarloNMSE.m and
exp_KpVsMonteCarloNMSE.m with the accelerated framework. Original CPM,
Proposed and Oracle curves are retained exactly as explicitly requested;
they are not replaced by the corresponding curves in these newer MAT files.
Consequently that historical combined figure was not a paired five-method run;
its Proposed curve used the original fitting implementation. The new experiment
replaces all panel data, including both modes in panel c, with accelerated results.

The original colors and all original curve data are preserved. Titles use
17 pt; axis labels, ticks and legends use 15 pt on a 1400-by-450 canvas.
All curves and legend samples use 2.5 pt line widths.
Panel (c)'s title stays on one line, its x ticks are reduced for readability,
and its custom legend uses a compact probability/Offline/Online table in the
empty upper-right region to avoid overlapping the curves.
Panels (a)/(b) extend their y-axis upper limits to display positive-dB
Pilot-only results and add legend entries. In panel (c), the custom legend
identifies the historical-snapshot curves as Offline and the instantaneous
horizontal references as Online, correcting the source script's swapped
labels without changing any curve data.
